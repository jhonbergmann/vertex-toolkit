## [1.0.0] - 2025-10-19

### Added
- Initial release of Vertex Toolkit
- 190+ utility functions across multiple categories:
  - **Validations**: CPF, CNPJ, CEP, email, phone, credit cards, passwords, URLs, strings, dates
  - **Masks**: Brazilian documents, phones, credit cards, currency, dates
  - **Formatters**: String cases, numbers, dates, file sizes
  - **Utilities**: Arrays, objects, functions, random generators, storage
  - **Generators**: Test data for CPF, CNPJ, persons, companies
- Complete TypeScript support with strict typing
- Zero external dependencies
- Cross-platform compatibility (Browser, Node.js, React Native)
- Tree-shakable exports for optimal bundle size
- Comprehensive documentation and examples
- Functional smoke tests
